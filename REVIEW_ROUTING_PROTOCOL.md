# Version 3: separate evaluation of positive-sensitive review routing

Dated internal plan, 9 October 2026. All original and version-2 results were known when designing this extension. This is not preregistration and does not revise the primary automatic finding-release results. The extension is an annotation-based review-flag experiment, not an automatic positive diagnosis or a performed radiologist review.

## Objective and locked rules

The patient-level target Z is the presence of at least one of the same seven NIH annotations. Review sensitivity is Pr(flag | Z=1). The complementary false-negative fraction is Pr(no flag | Z=1). Also estimate Pr(Z=1 | no flag), the annotation-positive fraction of unflagged patients. A no-flag action must never be represented as a normal radiograph, absence of all disease, or clinical clearance. No guarantee is claimed separately for each of the seven findings. Counts of flagged positives are distinct from automatically released positive diagnoses.

Use two fixed scores: (1) primary logistic stacking of the 14 frozen expert scores, and (2) maximum of the seven expert-mean scores. Fit the stacker ONLY on the original 846 NIH conformal-calibration patients, using standardized logit-transformed scores (clipped to [1e-6,1-1e-6]), LogisticRegression C=1, L2 penalty, lbfgs solver, max_iter=2000, no class weights, random_state=0. Fit normalization on those patients only. No hyperparameter search or test-based score selection. Save coefficients and environment. This task-specific fitted score does not alter the original experts or their finding-release gates; the new stacker is not a validated disease-probability estimator.

For each rule and threshold t in {0,.025,...,1}, flag when score >= t. On a NEW independent risk-calibration split, compute one-sided exact binomial upper bounds for both Pr(no flag | Z=1) and Pr(Z=1 | no flag). Use delta=.05 and M=2 scores x 41 thresholds x 2 endpoints=164, separately from the historical 308-rule family. Require both bounds <=.10; choose the largest passing threshold. This maximizes the unflagged count for that score because masks are nested. If no threshold passes, flag all patients: false-negative fraction is structurally zero and the unflagged conditional risk is undefined. Do not interpret a zero denominator as a zero conditional risk. Both methods and the always-flag comparator must be reported, including failures to certify. No threshold or method is chosen using evaluation outcomes.

## Independent new data

Acquire exactly converted NIH test shards 2, 3, 4, 5 from the same public mirror and immutable conversion commit efdd60f009509e6309d306f3681ac863b0c2fabb. Exclude all original 2,116 NIH patients AND all 1,582 version-2 replication patients, plus any selected-image duplicate. Select one image per remaining patient by minimum encoded-image SHA256 and remove cross-patient selected-image duplicates. No outcome-based inclusion. Preserve all source hashes, row references, exclusions and inference failures. If fixed shards are unavailable, report incomplete validation instead of selecting another subset by outcome.

Sort retained patient IDs, shuffle using NumPy default_rng(20261011), allocate floor(n/2) to routing-risk calibration and the remainder to a sealed evaluation split. Freeze the manifest before inference/evaluation. Calibration and evaluation are disjoint from each other, from the stacker fitting set and from every previously analyzed NIH patient. Apply the same two DenseNet releases, preprocessing, FP32 and disabled TF32. No image-derived model training on the new data. Use the previously downloaded source images only for the previously known analyses, not for new independent evaluation.

## Outcomes, uncertainty and implementation

On the new evaluation split, report counts, flag fraction, positive patients flagged, sensitivity, unflagged-positive fraction, and their patient-bootstrap percentile 95% intervals (2000 resamples, seed 20261012). Report per-finding flag sensitivity descriptively, without retroactive guarantees. Repeat for fixed 0.5 scores as uncertified comparators, without selecting among them. Provide exact descriptive binomial intervals for sensitivity and unflagged-positive fraction. These sampling intervals are separate from the simultaneous calibration bounds. Record the calibration candidate counts and both selected bounds. No clinical utility, measured human workload savings or external-center transfer is established.

Implement routing as a distinct enforced final action, with no diagnosis value. Incomplete, mismatched or invalid expert evidence must route to review. Validate actual graph replay under two deterministic schedulers and adversarial final planner prose. Preserve the original classifier gate and its conclusions. Add meaningful checks for denominator handling, exact bounds, leakage exclusions, score export and the final-action invariant. If the new results fail, report that failure without revising this protocol to manufacture success.
